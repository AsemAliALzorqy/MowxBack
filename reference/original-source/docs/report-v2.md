# تقرير الإصدار v2

## الملفات المعدلة
`js/app.js` (الحركات، التفاصيل، الحفظ، العملة، التقارير، الإعدادات)، `js/storage.js` (الترحيل)، `index.html` (ربط backup.js). ملف جديد: `js/backup.js`. نسخة v1 الكاملة محفوظة خارج الـZIP قبل التعديل.

## الوظائف الجديدة
- حركة أرباح واحدة تحتوي عدة أصناف (`lines`)، تظهر مرة واحدة في آخر العمليات والقوائم مع عدد الأصناف والكمية والإجمالي وزر عرض التفاصيل.
- نافذة تفاصيل: تعديل صنف وحذفه وإجمالي الحركة. الحذف **منطقي** (`deleted`) ويُسجَّل في سجل التغييرات؛ الحركة التي تُحذف كل أصنافها تُخفى (`void`).
- زر الحفظ يحفظ الصنف المكتوب في الحقول تلقائياً (صنف واحد بدون «إضافة إلى القائمة»)، مع منع الضغط المزدوج وتراجع كامل عند الفشل.
- العملات: SAR (﷼) وJOD وAED وKWD وUSD وEGP وخيار نص مخصص؛ تنسيق مركزي في `money()` عبر `Intl.NumberFormat`. القيم المخزنة لا تتغير.
- مجلد النسخ الاحتياطي (File System Access API) مع تنزيل يدوي بديل. هذا القسم لم يكن موجوداً في v1، فالتنزيل اليدوي أُضيف الآن.

## تغييرات التخزين
`v:2`. كل سجل ربح قديم يُحوَّل إلى حركة بصنف واحد بنفس المعرف دون دمج، وتُحفظ نسخة v1 في مفتاح `mowxback_demo_v1_backup_v1`. مجموع الحركة (`amount`,`qty`) يُعاد حسابه بعد كل تعديل.

## الاختبارات المنفذة
اختبار منطق بـNode (بدون متصفح): ترحيل بيانات v1 مع بقاء المعرفات والسجل ✔، إجمالي 120 ثم 125 بعد التعديل ثم 85 بعد الحذف ✔، الإخفاء عند حذف الكل ✔، صافي النتيجة دون تكرار ✔، تنسيق المبلغ ورمز ﷼ ✔. فحص صياغة كل ملفات JS ✔.

## لم يُختبر
واجهة المتصفح (النوافذ والنقرات وإعادة التحميل)، اختيار المجلد على Windows/Android ورفض الإذن، المقاسات من 360 إلى 1440px، وظهور الرمز ﷼ بخط ثمانية. الرمز الرسمي الجديد للريال (U+20C1) يحتاج خطاً يدعمه؛ المستخدم هنا ﷼ كما طُلب.
