# MowxBack — واجهة تجريبية

## المحتويات
- `index.html` الصفحة الوحيدة. `css/main.css` التنسيق. `js/utils.js` أيقونات (SVG بأسلوب Lucide مضمّنة بلا إنترنت) ودوال مساعدة. `js/storage.js` الحفظ المحلي والبيانات التجريبية. `js/app.js` الصفحات والمنطق.
- `docs/` و`assets/` للتوسعة لاحقاً.

## التشغيل
افتح `index.html` في المتصفح، أو شغّله من Spck Editor (Preview).

## النقل إلى Spck Editor
فك الضغط، ثم في Spck: افتح مشروع MowxBack ← أيقونة المجلد ← استيراد ← اختر الملفات والمجلدات (أو أنشئ الملفات بنفس المسارات).

## قرارات تقنية
- **الخط:** `Thmanyah Sans` مذكور أولاً في `font-family` مع بدائل (Tahoma/system-ui). لم أضمّن ملفات الخط لعدم التحقق من الترخيص؛ أضف كود التضمين من https://font.thmanyah.com/ في `index.html` (يعمل الخط تلقائياً).
- **الأيقونات:** SVG مضمّنة بأسلوب Lucide بدل CDN ليعمل دون إنترنت.
- **التصدير:** PDF عبر نافذة الطباعة ("حفظ كـ PDF")، وExcel بملف CSV يفتح في Excel.
- **السحبيات:** تُحسب ضمن إجمالي المصروفات مرة واحدة وتُعرض تفصيلاً مستقلاً.
- لا حذف للعمليات؛ كل إضافة/تعديل يُسجَّل في سجل التغييرات.
- لا مزامنة سحابية ولا نسخ احتياطي سحابي ولا PIN.
