# قائمة التحقق قبل إصدار MowxBack على Windows

هذه القائمة تمنع اعتبار نجاح اختبارات الوحدات دليلاً على جاهزية مثبت Windows. ضع علامة فقط بعد تنفيذ الاختبار فعلياً.

## قبل البناء

- [ ] مراجعة ملفات المشروع وعدم وجود بيانات تشغيل أو قواعد بيانات شخصية.
- [ ] مراجعة ترخيص الخطوط والأصول قبل إعادة توزيعها.
- [ ] تحديد ترخيص المشروع وإضافة `LICENSE` عند اختيار نشره مفتوح المصدر.
- [x] تضمين `package-lock.json` مطابق للإصدار `0.4.0`.
- [x] يستخدم سير CI الحالي Node.js 24 و`npm ci` بدلاً من `npm install`.

## GitHub Actions

- [ ] تشغيل `Build MowxBack for Windows` على `main`.
- [ ] التأكد من نجاح تثبيت dependencies.
- [ ] التأكد من نجاح إعادة بناء `better-sqlite3` لـElectron.
- [ ] التأكد من نجاح `npm test`.
- [ ] التأكد من نجاح `electron-builder` وإنشاء ملف EXE.
- [ ] تنزيل Artifact وفحصه.

## اختبار Windows الفعلي

- [ ] تثبيت التطبيق على Windows 10/11 x64.
- [ ] تشغيل التطبيق بعد فصل الإنترنت.
- [ ] اختبار إنشاء قاعدة جديدة واختيار مجلد البيانات.
- [ ] إضافة أرباح مفردة ومتعددة الأسطر، وإغلاق التطبيق وفتحه والتحقق من استمرار البيانات.
- [ ] تعديل وحذف سطر ربح والتحقق من الإجماليات وسجل التغييرات.
- [ ] إضافة مصروف وسحبية عامل والتحقق من عدم احتساب السحبيات مرتين.
- [ ] اختبار التقارير والفترات والعملات.
- [ ] إنشاء نسخة احتياطية وفحصها ثم استعادتها.
- [ ] اختبار نقل قاعدة البيانات ومقارنة السجلات والإجماليات.
- [ ] اختبار استيراد JSON حقيقي من النسخة القديمة على نسخة اختبارية، وليس على قاعدة الإنتاج مباشرة.
- [ ] اختبار ترقية قاعدة قديمة عند إضافة migrations مستقبلية.

## قرار الإصدار

لا يُعلن الإصدار مستقراً ولا تُستخدم قاعدة بيانات المصنع الفعلية قبل إكمال الاختبارات أعلاه وتوثيق النتيجة.
