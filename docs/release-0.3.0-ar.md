# MowxBack 0.3.0 — سجل الإصدار

## التغييرات

- معالجة إغلاق نافذة إدخال الأرباح عند سحب المؤشر لتحديد النص؛ أصبح إغلاق الخلفية يعتمد على بدء وانتهاء الضغط خارج النافذة، وليس مجرد وصول حدث النقر إلى الخلفية.
- تطوير محدد أصناف أرباح التقارير إلى وضعَي «جميع الأصناف» و«أصناف محددة» مع بحث متعدد التحديد وإزالة العناصر المحددة وتحديد نتائج البحث.
- نقل وضع «جميع الأصناف» إلى استعلام SQLite نفسه، مع تضمين أسماء الحركات التاريخية والأصناف الموقوفة في قائمة خيارات الاختيار عند استخدام الوضع المحدد.
- توحيد أوضاع الفترة للتقارير: يومي، شهري، ومن تاريخ إلى تاريخ، مع التحقق من صلاحية التاريخ ومنع عكس المدى.
- تحسين قوالب PDF والجداول، وإزالة عنصر التذييل المتدفق داخل المستند؛ يتولى تذييل الطباعة الأصلي عرض العلامة ورقم الصفحة.
- إضافة Diagnostic Logging يومي داخل مجلد بيانات المستخدم `Logs`، مع تنقية مفاتيح المعلومات الحساسة، ومدة احتفاظ قابلة للاختيار (7/14/30/60 يوماً)، وحالة السجلات وفتح المجلد وتصديرها من الإعدادات.
- رفع إصدار الحزمة إلى `0.3.0` وتوسيع مجموعة الاختبارات لتشمل اختيار الفترات ونظام السجلات.

## الاختبارات الآلية

يشغّل `npm test` اختبارات الحسابات، وSQLite، وRepository، وعقد IPC، وقوالب PDF، وسجلات التشخيص، ومدى التواريخ.

## التحقق الذي ما زال مطلوباً قبل إصدار Windows

لم يُجرَ في بيئة البناء هذه اختبار تفاعلي فعلي لنافذة Electron على Windows أو بناء مثبت NSIS. يجب تشغيل Workflow الخاص بـ GitHub Actions ثم تجربة المثبت على Windows بقاعدة اختبار منفصلة. كما ينبغي التحقق يدوياً من سحب النص بالفأرة، ومن فتح PDF الناتج من Electron نفسه؛ نموذج PDF المرفق معاينة للقالب وليست ناتج `printToPDF` من نسخة Windows.

## المسارات

- سجلات التشخيص: `%APPDATA%/MowxBack/Logs` (المسار الفعلي يتبع `app.getPath('userData')` في Electron).
- مدة الاحتفاظ الافتراضية: 14 يوماً.
- أمثلة السجلات: `docs/examples/`.
