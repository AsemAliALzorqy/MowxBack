# تسليم MowxBack 0.3.0

## ما تم تنفيذه

1. إصلاح إغلاق نافذة إدخال الأرباح عند سحب المؤشر لتحديد النص؛ الإغلاق من الخلفية يتطلب بدء الضغط وانتهاءه على الخلفية نفسها.
2. تطوير محدد أصناف أرباح التقارير: جميع الأصناف افتراضياً، أو بحث وتحديد متعدد وإزالة الأصناف المحددة وتحديد نتائج البحث.
3. جعل وضع جميع الأصناف استعلاماً مباشراً من SQLite دون توليد قائمة أسماء على الواجهة. قائمة الاختيار تجمع أسماء الكتالوج والحركات التاريخية، بما فيها الأسماء غير النشطة.
4. توحيد خيارات التاريخ في التقارير إلى يومي وشهري ومدى مخصص، مع تحقق تقويمي وحدود شهر صحيحة ورفض المدى المعكوس.
5. تحسين تنسيق PDF والجداول، إزالة التذييل الذي كان يتدفق داخل محتوى التقرير، وضبط اتجاه أرقام الصفحات في قالب Electron.
6. إضافة سجلات تشخيص يومية في مجلد `Logs` تحت مسار بيانات المستخدم، مع مدة احتفاظ قابلة للاختيار، وتنقية أسماء مفاتيح البيانات الحساسة، وحالة السجلات، وفتح المجلد وتصدير الملفات من الإعدادات.
7. رفع إصدار `package.json` و`package-lock.json` إلى `0.3.0`.

## معاينة PDF والسجلات

- `MowxBack-v0.3-Sample-Report.pdf` نموذج تقرير عام ببيانات اصطناعية معلّمة بأنها توضيحية، ست صفحات A4، وخط Thmanyah Sans مضمن. فُحص النص وعدد الصفحات وعُرضت الصفحات للتحقق من استمرار الجداول ورؤوسها وعدم وجود صفحة تذييل فارغة.
- `docs/examples/MowxBack-2026-11-25.log` مثال مولّد عبر وحدة DiagnosticLogger من جلسة اختبار اصطناعية. قيم مفاتيح الاختبار الحساسة تظهر بصيغة `[redacted]`.

**تنبيه:** ملف PDF المرفق معاينة للقالب تم توليدها بمحرك WeasyPrint بعد استخراج HTML الفعلي من قالب المشروع. لم يُنتج من `printToPDF` داخل Electron؛ لذلك لا يُعد بديلاً عن اختبار التصدير الفعلي في نسخة Windows.

## ما لم يُختبر بعد

- لم يتم تشغيل واجهة Electron تفاعلياً على Windows، ولذلك لم يُجرَ سحب فعلي للفأرة داخل نافذة الأرباح. تم التحقق من منطق أحداث المؤشر واختباره بعقد الواجهة، لكن يلزم الاختبار اليدوي على Windows.
- لم يتم تشغيل مثبت NSIS أو إعادة بناء `better-sqlite3` في هذه البيئة؛ يلزم تشغيل Workflow في GitHub Actions للتحقق من البناء الأصلي.
- يلزم إنشاء PDF من التطبيق نفسه على Windows للتأكد النهائي من تذييل Chromium وتدفق الصفحات في محرك Electron.
- لم يُختبر هذا الإصدار على قاعدة بيانات إنتاجية؛ حافظت التعديلات على مخطط SQLite ولم تُجرَ اختبارات مدمرة على بيانات فعلية.

بعد فك الأرشيف ونسخ محتوياته فوق نسخة المستودع المحلية:

```bash

```

```bash
git add -A
git commit -m "Release v0.3.0: report UX and diagnostic logging"
git push origin main
```

لا يتضمن هذا التسليم مثبت Windows؛ يتضمن الشيفرة المصدرية المعدلة وملفات الاختبار والتوثيق.
